# Security

## Reporting a vulnerability

Please report vulnerabilities privately, through GitHub's [private vulnerability reporting](https://github.com/apertrust/apertrust/security/advisories/new): the repository's Security tab, then Report a vulnerability. Do not open a public issue. Fixed vulnerabilities are published as [security advisories](https://github.com/apertrust/apertrust/security/advisories).

- You will hear back within 7 days.
- We aim to fix the issue and disclose it together with you within 90 days of the report.

## Supported versions

No version has been released yet. Only the main branch is supported.
