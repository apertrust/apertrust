# Fonts

IBM Plex Sans, the UI's typeface (architecture decision 36), in the three weights the design uses: Regular, Medium and SemiBold; and IBM Plex Mono in Regular alone, for the log window's lines.

- Source of Plex Sans: the `@ibm/plex-sans@1.1.0` release of https://github.com/IBM/plex, `ibm-plex-sans.zip` (SHA-256 `fb365d910566e6d199cc2c15579a7dd9a267128e18431a394ed81f1970c69200`), `fonts/complete/ttf/`; font version 3.005.
- Source of Plex Mono: the `@ibm/plex-mono@2.5.0` release of https://github.com/IBM/plex, `ibm-plex-mono.zip` (SHA-256 `6d23f01257663d8cc49a0d64c22ced630b79e0e2a0ac08a0da86e9a38bbc481c`), `fonts/complete/ttf/IBMPlexMono-Regular.ttf`; font version 2.005.
- Licence: SIL Open Font License 1.1, in `OFL.txt`, which is each release's `LICENSE.txt` unchanged: the two are the same text, copyright © 2017 IBM Corp. with Reserved Font Name "Plex".
- The files are unmodified. "Plex" is a Reserved Font Name, so a subset or otherwise changed file could not keep that name: update them only by copying a newer release's files.
