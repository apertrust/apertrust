# Fonts

IBM Plex Sans, the UI's typeface (architecture decision 36), in the three weights the design uses: Regular, Medium and SemiBold.

- Source: the `@ibm/plex-sans@1.1.0` release of https://github.com/IBM/plex, `ibm-plex-sans.zip` (SHA-256 `fb365d910566e6d199cc2c15579a7dd9a267128e18431a394ed81f1970c69200`), `fonts/complete/ttf/`; font version 3.005.
- Licence: SIL Open Font License 1.1, in `OFL.txt`, which is the release's `LICENSE.txt` unchanged.
- The files are unmodified. "Plex" is a Reserved Font Name, so a subset or otherwise changed file could not keep that name: update them only by copying a newer release's files.
